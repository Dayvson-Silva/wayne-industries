# Wayne Industries

## 📖 Sobre o Projeto

Este projeto consiste na página de login para o sistema interno da **Wayne Industries**. A interface foi desenvolvida para ser simples e intuitiva, permitindo que os diferentes tipos de usuários se identifiquem e acessem o sistema de acordo com seu nível de permissão.

---

## ✨ Funcionalidades

* **Interface de boas-vindas**: Saúda o usuário com uma mensagem amigável.
* **Seleção de Perfil de Usuário**: Oferece três níveis de acesso distintos:
    * Gerente
    * Administrador de Segurança
    * Funcionários
* **Design Responsivo**: A página se adapta a diferentes tamanhos de tela para uma melhor experiência do usuário .

---

## 🚀 Como Usar

1.  **Acesse a página** através do link: [https://dayvson-silva.github.io/wayne-industries/](https://dayvson-silva.github.io/wayne-industries/)
2.  **Selecione o seu perfil** clicando no botão correspondente (`Gerente`, `Adm Segurança` ou `Funcionários`).
3.  Após a seleção, você será redirecionado para a tela de autenticação apropriada para o seu nível de acesso.
